# gh-pages Set Up

## Windows

<https://jekyllrb.com/docs/installation/windows/>

1. [Install Ruby v3.x with DevKit](https://rubyinstaller.org/downloads/)
1. `ridk install`
    1. Option 1
    1. Option 3
1. `ridk enable`
1. `gem install bundler`
1. `bundle install`

### Run Dev Server

1. `ridk enable`
1. `bundle exec jekyll serve`
1. <http://127.0.0.1:4000/vufind/>
